# 클론이 안 될 때 직접 타이핑하는 짧은 프롬프트

## AGENTS.md 생성
AGENTS.md를 만들어라. 내용: 시험 맥락(과정도 채점, 나는 코드를 AI 없이 설명해야 함), 합의된 성공 기준(대화에서 정리, 모르면 질문), 작업 규칙(계획 승인 후 구현, 작게 구현하고 실행 결과로 보고, 작은 커밋, 시크릿 금지, 입력검증과 폴백, 문서와 코드 일치, 범위 확대 금지), 맨 위 STATE 줄(발굴 서면합의 스캐폴딩 E2E v0 중간검증 수용확인 제출의식)과 전환 전 3가지 자체감사(드리프트, 증거 없는 완료, 미확인 가정), 시간 보고, 마지막 제출 의식. 단계 전환, 컨텍스트 70%, 제출 직전에는 HANDOFF.md를 덮어쓴다(목표와 성공기준, 현재 단계, 완료와 증거, 다음 할 일, 설계 결정과 이유, 약점 파급 개선안, 실행법, 제외 범위). 코드는 쓰지 마라.

## 사용 순서
서면 합의 직후 실행하고, 실행 후에는 새 세션을 열어 AGENTS.md가 반영되게 한다.
