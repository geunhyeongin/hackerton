# 실무자 인터뷰 규칙 (본인이 메신저에서 질문할 때 쓰는 틀)

## 원칙
- 처음 3분은 "AI", "자동화", "머신러닝" 같은 해법 단어를 꺼내지 않는다.
- 안내 문서(README)에 적힌 내용도 실무자에게 사례와 숫자로 다시 확인한다.

## 질문 순서
1. 에피소드: "가장 최근에 이 일이 힘들었던 때를 처음부터 끝까지 얘기해 주세요."
2. 워크어라운드: "지금은 그걸 어떻게 버티고 계세요? 엑셀, 메신저, 사람에게 묻기?"
3. 정량화: "하루/주에 몇 건, 건당 몇 분, 실패하면 누가 얼마나 손해를 보나요?"
4. 당사자: "이 일로 가장 곤란한 사람은 누구인가요? 쓰는 사람은 누구인가요?"
5. 경계: "이건 절대 하면 안 된다 하는 게 있나요? 데이터 접근, 보안, 책임은요?"

## 문제 분석 렌즈
병목과 리드타임 / 비용과 손실 / 데이터 원천과 신뢰도 / 오류의 파급 / 수요 변동 / 유지보수 주체

## 인터뷰가 끝나면
대화 내용을 에이전트에게 주고 2-agreement.md의 프롬프트로 서면 합의문을 만든다.
