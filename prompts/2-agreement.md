# 서면 합의문 생성 프롬프트

아래 인터뷰 대화를 바탕으로 AGREEMENT.md를 작성해라. 코드는 아직 쓰지 마라.

형식:
1. 제가 이해한 문제 (3문장 이내)
2. 왜 생기나 (병목, 근거가 된 실무자 발언)
3. 성공 기준 (숫자, 현재값, 측정처. 숫자가 없으면 "미정"으로 표시하고 나에게 질문)
4. 만들 것 / 만들지 않을 것
5. 제약 (데이터, 보안, 환경)
6. 실무자에게 확인받을 질문 3개 이내

추측하지 마라. 대화에 없는 내용은 "미정"으로 둔다.
작성 후 이 내용을 AGENTS.md의 "1. 합의된 성공 기준"에 반영해라.
