# 제출물 기반 15분 이해도 훈련
아래 내용을 구현을 끝낸 프로젝트의 AI 대화에 붙여 넣는다. 사전 연습용이며 실제 AI 금지 평가에서는 사용하지 않는다.

---

실제 문항은 나중에 공개되고, 평가 때는 코드·문서·AI 없이 혼자 답해야 해.
지금 프로젝트의 최종 코드와 기록을 근거로 준비시키고, 예상 문항이 실제 출제를 보장한다고 말하지 마.
AGREEMENT는 목표 확인에 쓰되 실제 동작의 근거는 코드와 실행 기록에서 찾아.
지정된 공식 문서가 있으면 우선하고, 현재 프로젝트와 무관한 키트 예제를 제출 기능처럼 설명하지 마.

## 시작과 근거 확인
- 먼저 최종 코드·테스트·README·합의문·HANDOFF, 존재한다면 검증·AI 협업 기록을 읽어. 기록에 있는 파일/함수와 실제 구현을 대조해.
- 접근할 수 없는 자료는 위치를 물어보고 미확인으로 표시해. 검사가 존재하는 것과 실행 결과가 있는 것을 구분하고, 충돌은 숨기지 마.
- 구현 중 정리한 HANDOFF 9번을 활용해 준비 시간을 줄여. 재확인·읽기에도 시간이 들면 그 시간을 포함해.
- 내 '시작' 요청 시 실제 시작 시각과 15분 뒤 종료 시각을 기록해. 시각 도구가 없으면 내가 15분 타이머를 켜고 남은 시간을 알리게 해. 턴 수로 경과 시간을 꾸미지 마.
- 문항 준비가 끝나지 않아도 타이머가 시작됐다면 그 시간 안에서 핵심부터 진행해. 답변을 기다리는 시간도 포함해.
- 사전 반복 연습에서 내가 요청하면 시간을 늘릴 수 있지만, 기본 15분을 넘어 이해할 때까지 무한 진행하지 마.

## 0~4분: 핵심 설명
다음 여섯 항목을 전체 약 1쪽 분량으로 압축해. 한 항목을 길게 강의하지 말고 흐름과 핵심 판단부터 설명해.
1. 설계 선택: 선택·이유·대안·포기한 것. 사용자 확인과 AI 추정을 구분.
2. 데이터 흐름: 실제 입력 한 건 → 검증 → 계산/판정 → 결과 검증(있다면) → 저장 → 재조회/화면. 모듈별 책임과 상태 소유자.
3. 구현 범위: 구현·검증 완료 / 구현했지만 미검증 / 설계·가정 / 미구현, 다른 평가자의 재현 방법.
4. 실패 동작: 잘못된 입력·외부 실패·처리 중 데이터 변경과 기존 데이터/결과 보존, 남는 위험.
5. 검증 한계: 테스트가 보장하는 범위, 놓친 가정, 작은 반례·경계값과 추가 확인.
6. AI 협업: 실제 증상·제안·채택/수정/거절·판단 주체/근거·재검증. 기록에 없는 판단을 만들지 마.
핵심 알고리즘은 손으로 따라갈 작은 입력·중간 판단·결과로 설명하고, 실행하지 않은 예제는 '설명용 손계산, 실행 미검증'이라고 밝혀.

## 4~11분: 회상과 교정
- 나에게 코드·문서·앞선 설명을 보지 않고 답하도록 안내해. 실제로 자료를 덮었는지는 내가 확인하며 네가 확인했다고 주장하지 마.
- 여섯 유형을 짧게 두루 묻되 한 번에 한 문항만 내고 답변을 기다려. 시간 내 못 물은 항목은 미질문으로 남겨.
- 답변 전에는 해당 문항의 모범답안·힌트를 보여주지 마.
- 각 답변을 현재 동작 / 선택 이유 / 코드·실행 근거 / 한계의 관점에서 점검해. 관련 없는 기준은 적용하지 않아도 돼.
- '기억이 안 남'과 '개념을 이해하지 못함'을 구분하고 틀린 부분만 짧게 설명해. 구조는 데이터 한 건, 알고리즘은 작은 숫자 예제로 가르쳐.
- 설명 후 내 말로 다시 답하게 해. 같은 답을 반복하기보다 입력·제약·실패 시점을 바꿔 결과와 이유를 예측하게 해.
- 함수 이름 철자를 외우는 것보다 책임·상태·판단을 정확하게 설명하는 것을 우선해.

## 11~15분: 도움 없는 재시험
- 앞에서 약했던 부분부터 새로운 변형 질문을 한 번에 하나씩 내. 답하는 중에는 자료·힌트·교정을 제공하지 마.
- 내 답변 후 판정하고, 다시 질문할 시간이 없으면 새 설명을 길게 시작하지 마.
- 15분이 끝나거나 내가 종료하면 새 문제를 멈추고 아래 표를 출력해. 답변이 길어지면 다음 턴에서 실제 시각을 확인해 종료하고 초과를 솔직히 적어.

| 유형 | 상태 | 내 답변에서 확인된 근거 / 남은 오해 |
|---|---|---|
| 설계 선택 | 미질문 | |
| 데이터 흐름 | 미질문 | |
| 구현 범위 | 미질문 | |
| 실패 동작 | 미질문 | |
| 검증 한계 | 미질문 | |
| AI 협업 | 미질문 | |

상태는 미질문 / 미이해 / 도움 필요 / 독립 설명 / 변형 확인으로 기록해.
설명을 읽었거나 내게 '알겠다'는 말을 들었다고 통과시키지 마. 힌트 없이 정확하게 답하면 독립 설명, 새로운 조건에서도 설명하면 변형 확인이야.
자료 부족으로 판단할 수 없으면 상태 옆에 '근거 부족'을 적고 확인할 자료를 남겨. 공식 점수·합격을 보장하지 마.
마지막에는 기억할 핵심 최대 6줄과 남은 약점 최대 3개만 정리해. 실제 평가가 시작되면 AI 훈련을 종료해.
