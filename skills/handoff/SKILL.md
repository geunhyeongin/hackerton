# handoff

1. git status, git log --oneline -10, 최근 테스트 결과를 실제로 확인한다. 추측하지 않는다.
2. HANDOFF.md를 덮어써서 작성한다. 항목은 다음과 같다.
   - 목표와 합의된 성공 기준 (숫자 포함)
   - 현재 단계와 진척률 (통과한 기준 k/n)
   - 완료된 것 (파일 경로, 커밋 해시, 테스트 이름)
   - 다음 할 일 (우선순위 순)
   - 핵심 설계 결정과 이유, 대안
   - 알려진 약점과 장애 시나리오 (어디서 깨지는가 / 왜 위험한가 / 무엇을 검증할 것인가)
   - 실행 방법 (환경변수는 이름만)
   - 하지 않기로 한 것
3. git add HANDOFF.md 후 "handoff: 현재 단계"로 커밋한다.
4. 새 세션에서 쓸 첫 프롬프트를 한 문단으로 출력한다.

규칙: 시크릿 금지. "잘 동작함" 같은 표현 금지(확인한 명령을 적는다). 약점 항목은 매번 갱신한다.
